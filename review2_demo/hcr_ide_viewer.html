Flag 1 — fabricated evaluation numbers

evaluation/results/evaluation_report.json reports a perfect 1.0 on precision, recall, F1, and AUROC. This is not measured. evaluator.py's own __main__ block calls evaluate_with_pipeline(test_set, pipeline=None), and that branch hard-codes a score of 0.82 for every claim labeled "not hallucinated" and 0.25 for every claim labeled "hallucinated" — the comment above it literally says "Simulate a reasonable prediction for demo purposes." A perfect result on 19 claims with only two repeating scores is guaranteed by that shortcut, not earned by the models. The real code path already exists in the same function — it just needs an actual RAGHallucinationPipeline() instance passed in instead of None.

Flag 2 — unsourced comparison table

docs/07_TRUST_SCORE_AND_CONTROLLER.md presents a "Conventional RAG vs. this system" table (18.6% vs 2.1% hallucinated sentences, provenance 0.741 vs 0.936, latency 6.2s vs 9.8s) as measured results. Nothing in the codebase — including the evaluation report above — produces these numbers. They appear to be illustrative figures written without a "for illustration" caveat.
