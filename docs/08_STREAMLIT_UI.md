## What Is the Streamlit Dashboard?

The Streamlit dashboard is the **interactive front-end** of the TrustRAG system. It provides a visual interface that allows anyone (not just a programmer) to:
- Type a question
- See the retrieved evidence chunks and their similarity scores
- Read the generated response
- See exactly which sentences are verified, warned, or blocked
- View the similarity heatmap showing evidence strength per word
- Inspect the Trust Score and Provenance Score

---

## Why Streamlit?

**Streamlit** is a Python library that lets you build interactive web applications using only Python — no HTML, CSS, or JavaScript required.

| Reason | Detail |
|:---|:---|
| **Pure Python** | The entire dashboard is written in Python — no web development skills required |
| **Rapid prototyping** | You can build a functional dashboard in hours, not days |
| **Ideal for research demos** | Widely used in academic ML/NLP projects for demonstration |
| **Interactive widgets** | Text inputs, sliders, dropdowns, charts all available with single-line Python commands |
| **Lightweight** | Runs locally; accessible in any browser at `http://localhost:8501` |

---

## How to Run the Dashboard

```bash
# From the project root directory
streamlit run ui/app.py
```

Then open your browser and go to: `http://localhost:8501`

## What Is Displayed on the Dashboard?

### Panel 1: Query Input
- A text box where the user types their question
- A "Submit" button to run the full pipeline

### Panel 2: Retrieved Evidence
- Shows the Top-5 retrieved document chunks
- Each chunk displays:
  - The text content
  - The source file and page number
  - The cosine similarity score (colour-coded bar)

### Panel 3: Generated Response
- Shows the raw text generated by the local LLM
- Each sentence is colour-coded by its Trust Score:
  - 🟢 Green = Supported (T ≥ 0.75)
  - 🟡 Yellow = Weakly Supported (0.50 ≤ T < 0.75)
  - 🔴 Red = Hallucinated (T < 0.50)
- Inline source citations shown for supported sentences

### Panel 4: Trust Metrics
- Overall Trust Score (large gauge display)
- Provenance Score
- Hallucination Ratio (% of sentences that were flagged)
- Decision State: ANSWER / PARTIAL / BLOCKED badge

### Panel 5: Similarity Heatmap
- A word-level heatmap of the generated response
- Colour intensity shows how much evidence supports each word/phrase
- Uses Plotly for interactive visualization

### Panel 6: Decision State Banner
- Large coloured banner showing the final decision:
  - ✅ GREEN BANNER: "Answer provided with citations"
  - ⚠️ ORANGE BANNER: "Partial answer — some sentences flagged"
  - 🚫 RED BANNER: "Response blocked — insufficient evidence"
