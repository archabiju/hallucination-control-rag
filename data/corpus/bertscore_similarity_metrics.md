# BERTScore and Semantic Similarity Metrics

BERTScore is an automatic text-evaluation metric that measures how similar two pieces of text are in meaning, rather than in exact wording. It was originally proposed as a better alternative to older n-gram overlap metrics like BLEU and ROUGE, which count shared words or word sequences and therefore penalize a paraphrase even when it is perfectly correct. BERTScore instead encodes both texts (typically a "candidate" sentence and a "reference" sentence) into contextual token embeddings using a pretrained transformer such as BERT or a lighter model like DistilBERT, and then finds the best-matching pairs of tokens between the two texts using cosine similarity.

Concretely, for every token in the candidate text, BERTScore finds the reference token it is most similar to and records that similarity score; this produces a precision-like measure. It does the same in reverse — for every reference token, finding its best match in the candidate — producing a recall-like measure. The harmonic mean of these two directional scores gives BERTScore's F1, the number most commonly reported and used as a single similarity value between zero and one.

Because BERTScore operates on token-level embeddings rather than on whole-sentence embeddings, it captures finer-grained overlap than a single sentence-embedding cosine similarity would: a sentence can share most of its important content words with a reference while still being phrased differently, and BERTScore will reward that overlap where a cruder metric might not. This makes it a useful complementary signal alongside sentence-level cosine similarity and NLI entailment in a hallucination-detection pipeline — the three together check meaning-overlap at the sentence level (cosine), token level (BERTScore), and logical level (NLI entailment), so a claim that passes all three checks is supported in more than one independent sense, which is the rationale behind combining them into a single weighted "support score" rather than relying on any one signal alone.

One practical property of BERTScore worth noting is that it needs no training data of its own — it only needs a pretrained language model to produce embeddings — so it can be computed fully offline once that model is downloaded once, with no external API calls at inference time, which matches the offline design constraint of a local RAG hallucination-detection system.
